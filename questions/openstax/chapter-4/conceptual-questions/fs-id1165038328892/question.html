An object experiences acceleration directed at an angle with a nonzero x component. Does v_x change?

Yes. A nonzero a_x changes v_x with time.No. Only acceleration exactly along x can change v_x.No. Acceleration changes position but never velocity.Only v_y can change in two dimensions.

Resolve acceleration into components. Any nonzero x component is dv_x/dt and therefore changes v_x.
