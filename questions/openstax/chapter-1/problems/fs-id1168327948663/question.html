(a) What is [F] if F=ma?

ML/T^2ML/TML^2/T^2M/T^2

(b) What is [K] if K=0.5mv^2?

ML^2/T^2ML/T^2ML^2/TM/T^2

(c) What is [p] if p=mv?

ML/TML/T^2ML^2/TM/LT

(d) What is [W] if W=mas?

ML^2/T^2ML/T^2ML^2/TML^3/T^2

(e) What is [L_ang] if L_ang=mvr?

ML^2/TML/TML^2/T^2ML^3/T

Multiply the dimensions of factors: mass contributes M, each length contributes L, velocity contributes L/T, and acceleration contributes L/T^2.
