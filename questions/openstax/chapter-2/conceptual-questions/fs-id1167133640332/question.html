Can a scalar quantity be added directly to a vector quantity?

No; addition requires quantities of the same mathematical type and compatible physical dimensions.Yes; add the scalar to every component automatically.Yes; every scalar is a vector in an unspecified direction.Only when the scalar is negative.

A scalar cannot be combined by vector addition unless a physical rule first maps it to a vector.
