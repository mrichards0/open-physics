Distance from an odometer divided by trip time gives what?

Average speed.Magnitude of average velocity in every trip.Instantaneous speed.Average acceleration.

When does it equal the magnitude of average velocity?

For straight-line motion with no reversal.For every constant-speed trip.Only for a round trip.Whenever acceleration is nonzero.

Average speed uses distance. It matches displacement magnitude per time only when path length equals displacement magnitude.
