An object initially moves east at {{params.v0}} m/s. What constant signed acceleration makes its net displacement zero at t={{params.t}} s?

As t approaches infinity, the required westward acceleration approaches zero, but acts long enough to stop the object halfway through and return it with final velocity -v0.Acceleration approaches positive infinity.The object never reverses direction.

Set 0=v0t+(1/2)at^2 to obtain a=-2v0/t. Then vf=v0+at=-v0.
