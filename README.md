# Open Physics

PrairieLearn course content for the SpiritsFire adaptive STEM platform.

The initial module covers one-dimensional kinematics and uses selected,
attributed material from OpenStax University Physics Volume 1. See each
question's `source.json` for item-level provenance and adaptation details.

OpenStax-derived text, figures, and adaptations are distributed under the
Creative Commons Attribution-NonCommercial-ShareAlike 4.0 license. The
PrairieLearn question code is original project work unless a `source.json`
file says otherwise.
